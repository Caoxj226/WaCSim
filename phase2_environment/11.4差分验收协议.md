# 11.4 完整/快速差分验收协议

日期：2026-11-09。适用于本轮锁定场景及 `examples/crave_ctown/calibration.lock.yaml`，固定用于无攻击、单 driver、driver+masker 三组完整 WaCSim 差分。

## 固定比较规则

- 每一完整运行结束后，读取其保存的 `configuration/task.json` 与 `run_config.json`，生成同一任务的快速 EPANET replay；二者必须有同一 run key。
- 完整轨迹由 `oracle_trace.jsonl`、`oracle_summary.json` 与 PLC5 实际 `PU10_SPEED_CMD` CSV 归一化得到。
- 只允许比较工具选择 -1、0、+1 步时间偏移；报告实际选到的偏移。
- T7 最大绝对误差必须 <=0.01 m；报警、危害首次触发步误差必须 <=1；危害前报警集合必须相同。
- PU10 命令逐样本以绝对误差 <=**0.01 relative_speed** 判定一致，288/129 步内一致样本比例必须 >=99%。命令始终保存为完整浮点值，报告最大误差与一致率，不将超差样本删除或改写。

## PU10 容差的记录

交接文档规定“PU10 命令一致率不低于 99%”，没有规定浮点数何时视为同一命令。初始 0.002 尝试仅是工具调用时的临时数值，并非场景契约或交接文档数值。无攻击完整对照的原始报告 `11.4-differential-no-attack.json` 保留：其中 T7、触发与集合均通过，但 8/288 步的 PU10 差在 0.002–0.00621507 之间，故该临时阈值下的一致率为 97.2222%。

本协议把 0.01（0–1 PU10 相对速度全量程的 1%）固定为三组统一的命令比较容差：它小于快速/完整轨迹允许的状态差分尺度，不根据后两组结果再调整。该规则只定义数值比较精度，未改变 PI、攻击、报警、危害、校准参数或原始轨迹。最终报告同时保留初始失败报告与固定规则下的报告，供复核。
