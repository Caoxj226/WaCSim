# 正常 SP 与 PI 候选配置

制定日期：2026-11-07。师兄反馈“合理即可”，用户授权制定候选值和范围。本文件固定无攻击校准的候选集与积分配置。已运行 48 组快速 EPANET 无攻击探索；候选仍未通过完整平台验证或成为最终参数。

## 固定候选集

| 参数 | 固定候选 | 本次候选范围 |
| --- | --- | --- |
| 正常 T7SP（m） | 2.5、3.0、3.5，按此优先顺序 | 2.5–3.5 m |
| Kp（相对泵速/m） | 0.2、0.4、0.8、1.2 | 0.2–1.2 |
| Ki_per_step（相对泵速/每步累计的 m 误差） | 0.005、0.01、0.02、0.04 | 0.005–0.04 |

只测试列出的离散点，区间内不自动插入其他值。每个 SP 对应 4×4=16 组 PI 参数，最多 48 组。

正常 SP 的候选范围与攻击可写范围是不同概念：正常值从上述三项选择，SP 攻击可写范围仍为 0–5 m。PU10 命令输出范围仍为 0–1。原攻击斜率与 duration 范围不变。

## 为什么选这些值

- T7 模型允许液位为 0–5 m，低液位危害线为 0.5 m。2.5 m 位于模型液位范围中间，距两端各 2.5 m，距危害线 2.0 m，作为首选正常目标有明确的几何余量。它也恰好等于原始初始水位，但并非从原控制器继承的 SP。
- 3.0 m 和 3.5 m 提供更高液位的正常候选，距模型上限仍分别有 2.0 m 和 1.5 m。旧开关控制基线在这些液位附近运行过，但这不能证明新增 PI 在这些 SP 下已经稳定。
- Kp 让 0.5 m 的当前误差产生 0.1、0.2、0.4、0.6 的比例输出，覆盖从较缓和到较强的调节力度；误差更大时由 0–1 输出限幅处理。
- 持续 0.5 m 误差下，四个 Ki 候选每步分别增加 0.0025、0.005、0.01、0.02 的积分输出；连续一小时（12 步）分别增加 0.03、0.06、0.12、0.24，前提是未发生限幅/积分冻结。这样覆盖不同的误差补偿速度。
- 以上是事先制定的量级合理的探索网格，不是通过辨识模型推导出的稳定区间，也没有根据攻击结果调节。旧 PU10 开关对照证明泵可以影响 T7，但不能据两次轨迹精确求出最优 PI 参数。

## 明确积分的定义

继续采用场景契约的离散计算形式，其中每一步为 300 秒：

```text
e[k] = SP[k] - PLC5_cached_T7[k]
I_candidate = clamp(I_previous + e[k], 0, 1 / Ki_per_step)
u_raw = Kp * e[k] + Ki_per_step * I_candidate
若 u_raw > 1 且 e[k] > 0，或 u_raw < 0 且 e[k] < 0：保留 I_previous
否则：接受 I_candidate
u_PI = clamp(Kp * e[k] + Ki_per_step * I_current, 0, 1)
```

每个候选运行开始时 I=0。连续运行期间，包括跨天和预热结束时，都不重置积分；更换候选后恢复相同初始水力状态并将积分归零。

积分下限为 0，上限按 Ki 求出，使积分贡献 Ki×I 始终位于 0–1：

| Ki_per_step | I 下限 | I 上限 |
| --- | --- | --- |
| 0.005 | 0 | 200 |
| 0.01 | 0 | 100 |
| 0.02 | 0 | 50 |
| 0.04 | 0 | 25 |

选择非负积分贡献是针对本场景单向泵速 0–1 的设计；负误差仍可逐步减少已有积分。这不是所有 PI 的通用积分范围，也不保证这些候选都合格。

这里 Ki 已按一个 300 秒采样步定义，公式中不得再乘 300。若对接按秒积分的库，应使用 Ki_per_second=Ki_per_step/300。离散积分增益和采样时间必须对应，条件积分/钳位也是已有的防饱和方法；参见 [MathWorks 离散 PID 文档](https://www.mathworks.com/help/simulink/slref/discretepidcontroller.html) 和 [anti-windup 说明](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。这两份文档支持实现约定，不是本文件具体候选数值的来源。

## 选取规则与当前边界

1. 在没有攻击的条件下，固定 SP=2.5 m，按 Kp 升序、Ki 升序检查其 16 组 PI。
2. 按交接文档淘汰触发主危害、输出饱和比例超过 0.25 的组合，并应用完成后的多周期稳定性标准。
3. 如果有合格组合，在这个 SP 下按 T7 tracking MAE 选 PI；不因其他 SP 的攻击效果更好而换 SP。
4. 若此 SP 下所有 PI 均不合格，依次检查 3.0 m、3.5 m；首个存在合格 PI 的 SP 即被选中。
5. 48 组全部不合格则停止，保留失败原因并修订候选协议；不得临时扩大范围后不记录，也不得根据危害攻击是否成功调正常配置。
